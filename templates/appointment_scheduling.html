{#- TITLE WORDING. "New Appointment" was the last thing on this screen repeating that phrase, and a dialog does need to name itself -- an untitled popup is a real regression, not a tidier screen -- so it was reworded rather than removed. The id is untouched because aria-labelledby on the modal points at it. "Schedule Appointment" and not "Book Appointment", for two reasons. The submit button below already says Book Appointment, and a header repeating its own button is a wasted line. More importantly the submit is not always that: choosing "new patient" switches it to Continue to Registration, because this dialog can hand off to registration on the way to a booking. A title has to cover both modes, and Schedule does.
